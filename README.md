# Nigeria DHS Immunization Analysis

A reproducible R-based research pipeline for analysing childhood immunization using the Nigeria Demographic and Health Surveys (NDHS) 2013, 2018, and 2023–24.

## Overview

This repository provides a standardized analytical workflow for producing high-quality, reproducible evidence on immunization system performance in Nigeria. It supports multiple peer-reviewed publications using harmonized NDHS datasets and transparent analytical methods.

## Research Objectives

- Assess immunization coverage and equity.
- Quantify zero-dose prevalence and immunization dropout.
- Evaluate maternal and child healthcare continuity.
- Measure subnational immunization system performance.
- Generate reproducible figures, tables, and supplementary materials.
